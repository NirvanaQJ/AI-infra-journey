## 函数调用：参数、保存规则和栈帧

本机 Linux x86-64 对常见整数与指针参数依次使用 `%rdi`、`%rsi`、`%rdx`、`%rcx`、`%r8`、`%r9`；常见整数返回值在 `%rax`。`call` 压入返回地址，`ret` 取出它。`%rbx`、`%rbp`、`%r12`～`%r15` 属于被调用者保存组；若被调用函数改动它们，返回前应恢复。`%rax`、`%rcx`、`%rdx`、`%rsi`、`%rdi`、`%r8`～`%r11` 属于调用者保存组；调用者若仍需旧值，应自行保存。

### 真实栈帧中的保存位置

上一关 `phase_2` 有 `push %rbp; push %rbx; sub $0x28,%rsp`。设这三条执行完后 `%rsp=R`：

| 地址 | 内容 |
| --- | --- |
| `R+0x38` | `call phase_2` 压入的返回地址 |
| `R+0x30` | 保存的旧 `%rbp` |
| `R+0x28` | 保存的旧 `%rbx` |
| `R+0x18`～`R+0x27` | 额外预留空间 |
| `R+0x00`～`R+0x17` | 六个 `int`，每个 4 字节 |

`phase_2` 后来把 `%rbp` 用作数组结束指针，说明 `%rbp` 不一定是帧指针。保存槽的作用是让它能临时改用这个寄存器，并在返回前恢复调用者的旧值。

## `phase_4`：输入、调用和递归逻辑

用 `objdump -d --disassemble=phase_4 ./bomb` 与 `objdump -d --disassemble=func4 ./bomb` 查看实际指令。`sscanf` 的格式串地址 `0x4025cf` 为 `"%d %d"`，所以要输入两个整数 `x y`，分别存于 `8(%rsp)` 和 `12(%rsp)`。成功转换个数必须为 2；`cmpl $0xe,8(%rsp)` 后的无符号 `jbe` 要求 `x` 在 `0..14`。

调用前把 `x` 放入 `%edi`、0 放入 `%esi`、14 放入 `%edx`，故调用等价于 `func4(x, 0, 14)`。`y` 没有传给 `func4`，而是在调用返回后检查。`func4` 返回值必须为 0，同时 `y` 必须为 0。

在有效区间内，`func4` 的中点计算可理解为 `mid = low + (high-low)/2`，分支逻辑可写为：

```c
int func4(int x, int low, int high)
{
    int mid = low + (high - low) / 2;
    if (x < mid) return 2 * func4(x, low, mid - 1);
    if (x > mid) return 2 * func4(x, mid + 1, high) + 1;
    return 0;
}
```

### 用 `3 0` 观察两层调用

| 层次 | 参数 | 中点 | 动作与结果 |
| --- | --- | ---: | --- |
| 外层 | `func4(3,0,14)` | 7 | `3 < 7`，递归调用 `func4(3,0,6)`。 |
| 内层 | `func4(3,0,6)` | 3 | 相等，直接返回 `%eax=0`。 |
| 回到外层 | — | — | 执行 `add %eax,%eax`，得到 `2×0=0`，返回 `phase_4`。 |

内层的 `ret` 返回到外层递归调用之后的 `0x400fee`；外层的 `ret` 才返回到 `phase_4` 的 `0x40104d`。在 `phase_4` 中，`test %eax,%eax` 检查递归结果，随后比较 `y` 与 0，因此 `3 0` 通过。

### 两层递归时的栈变化

设 `phase_4` 执行 `sub $0x18,%rsp` 后 `%rsp=P`。它的输入在 `P+8` 与 `P+12`，来自调用者的返回地址在 `P+0x18`。递归最深处，各层按从高地址到低地址排列：

| 相对 `P` 的地址 | 内容 |
| --- | --- |
| `P+0x18` | `phase_4` 返回其调用者的地址 |
| `P+0x08`、`P+0x0c` | 输入 `x=3`、`y=0` |
| `P-0x08` | 外层 `func4` 返回 `phase_4` 的地址 `0x40104d` |
| `P-0x10`～`P-0x09` | 外层 `func4` 预留的 8 字节 |
| `P-0x18` | 内层 `func4` 返回外层的地址 `0x400fee` |
| `P-0x20`～`P-0x19` | 内层 `func4` 预留的 8 字节；此时 `%rsp=P-0x20` |

每次递归 `call` 压入 8 字节返回地址，`func4` 开头又用 `sub $0x8,%rsp` 预留 8 字节，因而多一层调用时栈顶再向低地址移动 16 字节。`func4` 没有 `push %rbx` 或 `push %rbp`，所以这两层没有相应的保存槽。返回时先释放本层 8 字节，再由 `ret` 弹出本层返回地址，按相反顺序逐层恢复。
