## IEEE 754 结构地图

| 类型 | 符号位 `s` | 指数字段 `exp` | 小数字段 `frac` | 指数偏置 |
| --- | --- | --- | --- | --- |
| `float` | 1 位 | 8 位 | 23 位 | 127 |
| `double` | 1 位 | 11 位 | 52 位 | 1023 |

### 三种模式

以下以 `float` 为例：

| 模式 | 条件 | 数值 / 含义 |
| --- | --- | --- |
| 规格化 | `exp` 非 0、非 255 | `(-1)^s × 1.frac × 2^(exp - 127)` |
| 非规格化 | `exp` 全为 0 | `(-1)^s × 0.frac × 2^(-126)`，用于表达接近 0 的数，实现逐渐下溢；`frac = 0` 时表示正零或负零。 |
| 特殊值 | `exp` 全为 1 | `frac = 0` 表示正无穷或负无穷；`frac ≠ 0` 表示 NaN。 |

### 1. bitXor：实现按位异或

```c
int bitXor(int x, int y) {
    return ~(~(x & ~y) & ~(~x & y));
}
```

思路：使用 `~` 和 `&` 实现异或。

### 2. tmin：返回补码整数的最小值

```c
int tmin(void) {
    int a = 1;
    a = a << 31;
    return a;
}
```

### 3. isTmax：判断是否为补码整数的最大值

```c
int isTmax(int x) {
    return !(~(x ^ (x + 1))) & !!(x + 1);
}
```

### 4. allOddBits：检查所有奇数编号位是否为 1

```c
int allOddBits(int x) {
    return !(~((x & 0xFFFFFFFF) | ~0xAAAAAAAA));
}
```

笔记：与全为 `1` 的掩码 `0xFFFFFFFF` 做按位与，结果仍是原来的位模式。

待修改：上述实现直接使用了 `0xFFFFFFFF` 和 `0xAAAAAAAA`，超过整数题允许的常量范围（`0` 到 `255`）。需要使用小常量、移位和位运算构造掩码，再通过 `dlc` 检查。

### 5. negate：返回相反数

```c
int negate(int x) {
    return ~x + 1;
}
```

思路：在实验的补码模型下，取负可以通过按位取反再加一实现。
