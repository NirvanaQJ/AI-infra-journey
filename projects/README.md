# 跨周项目

这里收纳需要持续开发、测试和复现的作品。按学习计划，预计先后建立：

| 周次 | 项目 | 主要证据 |
| --- | --- | --- |
| W5–W6 | `high-perf-server/` | 架构、启动命令、并发测试与 `perf` 记录 |
| W12–W13 | `rdma-benchmark/` | Verbs 程序、环境、RDMA/TCP 对照数据 |
| W19–W22 | `training-communication/` | CUDA/NCCL/训练基线、原始数据、瓶颈分析与复现报告 |

每个项目开始时再创建目录，并在内部放 `README.md`、源码、运行脚本、`results/` 和必要的图文说明。原始性能数据应记录硬件、软件版本、输入规模、预热、同步方式和重复次数；未实测的结论明确标注。
